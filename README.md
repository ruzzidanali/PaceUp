# PaceUp

A Strava-inspired fitness tracking platform built for learning,
portfolio development, and personal use.

## Tech Stack

- ASP.NET Core
- C#
- PostgreSQL
- PostGIS
- Flutter
- React
- TypeScript
- Redis
- SignalR
- Docker

## Architecture

PaceUp uses a modular monolith architecture with:

- API
- Application
- Domain
- Infrastructure
- Background Worker
